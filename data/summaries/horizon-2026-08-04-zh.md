## [华为发布“韬定律”：以时间缩微替代几何缩微](https://t.me/zaihuapd/42966) ⭐️ 9.0/10

在 2026 年上海国际电路与系统研讨会上，华为提出“韬定律”（τ定律），主张以“时间缩微”替代“几何缩微”作为半导体演进的新原则。华为称过去六年已据此设计量产 381 款芯片，今年秋季将推出采用逻辑折叠技术的新麒麟手机芯片。 如果华为的说法成立，“韬定律”将在摩尔定律逼近物理极限之际开辟一条新路径：通过优化时间而非缩小晶体管来提升芯片性能。这可能重塑业界对芯片缩放预期的共识，影响竞争对手的技术路线图，并为华为提供一条不依赖最先进 EUV 光刻、即可达到接近 1.4 纳米制程晶体管密度的替代路径。 “韬定律”以统一的特征时间常数τ作为优化目标，在器件、电路、芯片和系统四个层级进行协同优化。华为的“逻辑折叠”技术通过垂直堆叠层来提升晶体管密度，据称可将 AI 计算的晶体管密度提升 53%；华为预计到 2031 年实现相当于 1.4 纳米制程的水平。

telegram · zaihuapd · 8月4日 08:04

**背景**: 几十年来，半导体行业一直遵循摩尔定律，通过“几何缩微”——即缩小晶体管的特征尺寸——大约每两年让晶体管密度翻倍。随着这种微型化逼近物理极限，性能提升速度开始放缓、成本不断上升。华为的“韬定律”提出将主要优化目标从晶体管面积转向时间，在多个系统层级系统性地降低时间常数τ。逻辑折叠则是在结构维度上延伸这一思路，通过垂直堆叠芯片层来增加密度，而不是继续缩小晶体管尺寸。

## [联邦快递的混乱邮件说明用户为何屡屡中网络钓鱼招](https://www.troyhunt.com/thanks-fedex-this-is-why-we-keep-getting-phished/) ⭐️ 8.0/10

在 2024 年的文章中，Troy Hunt 以联邦快递（FedEx）令人困惑的邮件做法为例，说明合法服务如何教导用户接受类似网络钓鱼的邮件。他认为真实邮件与欺诈邮件之间的界限已变得极其模糊。 这之所以重要，是因为合法公司会在无意中削弱用户的警惕性，使网络钓鱼攻击更易得手、更难防范。当受信任的品牌示范糟糕的邮件行为时，普通用户、安全团队和企业都会深受其害。 Troy Hunt 特别指出，合法联邦快递通知可能来自看似个人发件人的邮箱并附带 PDF 附件，这与诈骗手法极为相似。邮件客户端通常会先显示显示名而非完整地址，攻击者便利用这一点进行显示名欺骗（display name spoofing）。

hackernews · stymaar · 8月4日 21:09 · [社区讨论](https://news.ycombinator.com/item?id=49175192)

**背景**: SPF、DKIM 和 DMARC 等电子邮件认证协议旨在识别虚假发件地址，并告知接收服务器如何处理未通过校验的邮件。然而，显示名欺骗仍然有效，因为大多数邮件客户端会先显示发件人的友好名称，再显示完整地址，用户难以快速核实真实发件人。当合法公司发出看起来像网络钓鱼的邮件时，用户就会被“训练”得对这些警示信号习以为常。

## [在单块 AMD MI300X 上运行 DeepSeek V4 Flash](https://github.com/ryanzhou/deepseek-v4-flash-mi300x) ⭐️ 8.0/10

一个 GitHub 仓库和技术指南展示了如何在单块 AMD MI300X 加速器上运行 DeepSeek V4 Flash，通过量化将模型装入可用显存。社区讨论强调了实际取舍，包括上下文窗口从原生 1M 降至 256K 这一点。 这说明 284B 参数的混合专家（MoE）模型可以在单块 GPU 上部署，有望降低 AI 推理的硬件成本。这也凸显了 AMD MI300X 在运行最新开源权重模型方面日益增强的实用性。 DeepSeek V4 Flash 总参数为 284B，每个 token 激活 13B 参数，原生支持 1M token 上下文。MI300X 是拥有 192GB HBM 的 OAM 模块，通常以 8 卡整机形式销售，该指南将上下文窗口降至 256K token 以适应硬件。

hackernews · zhoutong · 8月4日 10:00 · [社区讨论](https://news.ycombinator.com/item?id=49166386)

**背景**: DeepSeek V4 Flash 是一种混合专家（MoE）模型，意味着每个 token 只激活其中一部分参数，从而降低推理时的计算量和内存占用。量化是一种将高精度权重转换为低精度格式的技术，可在质量损失很小的情况下缩小模型的内存占用。AMD Instinct MI300X 是基于 CDNA 3 架构的 GPU 加速器，面向大规模 AI 和 HPC 工作负载设计。

## [Keyv 及相关 npm 包在 Shai-Hulud 供应链攻击中遭入侵](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack) ⭐️ 8.0/10

流行的 npm 包 Keyv 及多个相关包在一场正在进行的 Shai-Hulud 供应链攻击中被入侵。据微软、Palo Alto Networks 和 Wiz 的安全研究人员称，该攻击利用一种自我复制的蠕虫在 npm 生态系统中传播恶意代码。 这很重要，因为 Keyv 是一个广泛使用的键值存储库，下载量达数百万，因此该入侵可能影响大量下游应用程序。同时，它也凸显了 npm 安装脚本的系统性风险，以及清理供应链攻击的难度。 已知 Shai-Hulud 蠕虫会通过 npm 包中的 pre-install 和 post-install 钩子执行恶意代码。社区推荐的缓解措施包括在 .npmrc 中设置 'min-release-age=5'，以及审计 node_modules 中的可疑包。

hackernews · cimi_ · 8月4日 11:01 · [社区讨论](https://news.ycombinator.com/item?id=49166874)

**背景**: Keyv 是一个用于 Node.js 的简单键值存储模块，支持内存、Redis 和 SQLite 等多种后端。Shai-Hulud 是一种自我复制的 npm 蠕虫，于 2025 年 11 月下旬首次被披露，它通过窃取凭证并借助安装钩子传播，已危及数百个包和数千个仓库。供应链攻击利用了开发者与依赖包之间的信任关系，对软件生态系统构成严重威胁。

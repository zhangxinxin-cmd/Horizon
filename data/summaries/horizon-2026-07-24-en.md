## [Security camera ships with hardcoded GitHub admin token](https://hhh.hn/hanwha-github-token/) ⭐️ 8.0/10

A security camera was discovered to contain a hardcoded GitHub personal access token with admin privileges in its login page source code, exposing the vendor's private repositories and secrets. This vulnerability highlights systemic security failures in IoT devices, where hardcoded credentials can lead to supply-chain attacks, data breaches, and unauthorized access to critical infrastructure. The token, found in the camera's web login page HTML, had full access to the vendor's GitHub organization, including private repositories and CI/CD pipelines. This is a classic example of hardcoded credential vulnerability (CWE-798).

hackernews · hhh · Jul 24, 11:54 · [Discussion](https://news.ycombinator.com/item?id=49034292)

**Background**: GitHub personal access tokens (PATs) are used to authenticate API requests and command-line operations, and can grant broad permissions to user or organization accounts. Hardcoded credentials—such as passwords, API keys, or tokens embedded directly in source code or device firmware—are a well-known security anti-pattern because they allow anyone who obtains the code to reuse the credentials without proper access control. In IoT devices, such vulnerabilities are particularly dangerous due to the difficulty of patching and the large number of deployed units.

## [Compiler turns computation graphs into transformer weights without training](https://www.reddit.com/r/MachineLearning/comments/1v5fxbe/i_built_a_compiler_that_turns_computation_graphs/) ⭐️ 8.0/10

A new compiler, TorchWright, takes ordinary Python computation graphs and outputs a standard Phi-3 checkpoint that can be loaded directly in vanilla Hugging Face, with zero training involved. This enables researchers to directly study what algorithms transformers can express, separate from learning, and provides a practical tool for hand-crafting transformer weights that work on stock architectures. The compiler targets the Phi-3 architecture and outputs a checkpoint loadable without custom code or trust_remote_code. It includes twelve runnable examples in the repository.

reddit · r/MachineLearning · /u/notforrob · Jul 24, 16:15

**Background**: Prior work like RASP and Tracr compiled domain-specific languages into transformer weights, but required custom architectures or non-standard code. TorchWright improves by using ordinary Python and targeting a stock architecture (Phi-3) that is widely supported in Hugging Face Transformers. The Phi-3 model is a small language model by Microsoft, with a standard transformer decoder architecture.

The global DRAM market has long been dominated by three players: Samsung, SK Hynix, and Micron. CXMT (ChangXin Memory Technologies), based in Hefei, China, is the country's first major DRAM manufacturer, having started volume production around 2019.
